RSFM

Road Surface Fracture Model. Upload a road-crack image, compare it with a repaired reference crack, and forecast the repair year.

Planning prototype: RSFM uses editable default thresholds and factor shares. Agencies should replace them with local standards and observed pavement data before real repair decisions.
1

Set agency default tables

These values are editable. An agency can enter its own repair thresholds and factor shares before running a forecast.

2

Add the image

Upload a crack photo manually or import a RoadScan image record.

3

Measure the crack

The engineer selects the crack type and enters its current length, width, and depth in centimetres.

4

Add repaired Road A

Use a comparable road where the same crack type has reached its repair threshold. Its average growth establishes the base rate.

5

Add Road B conditions and forecast

RSFM compares Road B with Road A using traffic, heavy vehicles, freeze months, rain months, and pavement age.
