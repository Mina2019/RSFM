How to work with calibration

  1. Collect repeated yearly length, width, and depth measurements for many fracture locations.
  2. Include each location’s traffic, truck, freeze-thaw, precipitation, and pavement-age data.
  3. Load the historical table and estimate the three equations.
  4. Test predictions against later inspection years before using them for planning.
  5. Update the model as new inspection data arrives.
